# Obay Ehab — portfolio (static site)

Crumpled grid paper, extended black type, torn edge and marquee strips. No server needed.

## Preview
Open `index.html`, or run `python3 -m http.server 3000` here and visit http://localhost:3000

## Add two things
- `images/obay.jpg` — your portrait (3:4). Until it exists a script "Obay" monogram shows.
- `logos/icpc-zewail-city.png` — ICPC Zewail City logo (transparent PNG). Until it exists a text version shows.

## Publish on Hostinger
hPanel → File Manager → `public_html` → upload everything in this folder (index.html at the top level). Done.

## Edit
- Work items & descriptions: top of `script.js` (SECTIONS)
- Colours / fonts: top of `style.css`
- Email & LinkedIn: `index.html` (contact section)
